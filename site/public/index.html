Developer preview

You can’t install Companion for Mentra yet. It has no public download or store listing, and its source repository is private, so it runs only if Companion Intelligence gives you access. To ask about access or follow progress, join the Discord or read the Mentra Live docs.

Mentra is retiring the app type this bridge uses (Cloud SDK apps). They keep running only on Mentra’s separate MentraOS Legacy build, and Mentra says support for that build ends in October 2026.

How it works

  1. GlassesMentra Live picks up your voice
  2. MentraOSSends the audio to your bridge’s public HTTPS address
  3. Companion for Mentra bridgeRuns on your Companion Hub or a server you control. Ports 7010 (AppServer) and 8080 (UI + API)
  4. Speech-to-textThe bridge sends each utterance to an OpenAI-compatible endpoint you provide, such as a local Whisper server
  5. Companion HubYour local model answers: Ollama or the hermes / openclaw agent
    Companion MemoryRecalls what you told it before and saves each exchange: profile, recall, turns
  6. MentraOS voiceThe bridge speaks the reply back through your glasses with the MentraOS text-to-speech voice

Audio passes through MentraOS. Answers are generated on your Hub, and your conversations and saved memories are stored only in your own Companion Memory, but the audio and transcripts do travel through Mentra’s service on the way.

The phone and R1 ring UI is served by the bridge itself at https://<your-bridge>/. This site hosts a demo of that UI with canned answers, so you can see what it looks like.

Setup

These steps are for developers who have been given access to the bridge. Fill the form in to generate your .env. Nothing you type leaves this page. The file is built in your browser, then copied or downloaded.

  1. Register the app in MentraOS needs access

    In the MentraOS developer console, create an app. Set its Public URL to the HTTPS address that reaches your bridge on port 7010, for example a Tailscale Funnel or Cloudflare Tunnel hostname. Copy the package name and API key.

    A Cloud SDK app needs Mentra’s MentraOS Legacy build. As of 3 October 2026 the console shows only a “coming soon” page, so new apps can’t be registered there yet.

  2. Get a Companion Memory key

    Companion Memory uses a memory-scoped API key sent as x-api-key. It is not your Companion Intelligence sign-in. Issue one in Companion Memory the same way you do for the Hermes and OpenClaw plugins.
