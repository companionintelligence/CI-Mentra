Companion Intelligence · Device layer

Your companion, in your glasses.

CI-Mentra connects Mentra glasses to your own Companion Hub and memory. You speak, it recalls what you told it before, and it answers out loud. Your conversations stay on hardware you control.

Set up your bridge Open the companion UI demo

How it works

  1. GlassesMentra Live picks up your voice
  2. MentraOSStreams the transcript to your app's public URL
  3. CI-Mentra bridgeRuns on your Hub or server. Ports 7010 (AppServer) and 8080 (UI + API)
  4. CI-HubLocal inference: Ollama or the hermes / openclaw agent
    CI-ServerCompanion Memory: profile, recall, turns

The phone and R1 ring UI is served by the bridge itself at https://<your-bridge>/. This site hosts a demo of that UI with canned answers, so you can see it before you install.

Setup

Fill this in to generate your .env. Nothing you type leaves this page. The file is built in your browser, then copied or downloaded.

  1. Register the app in MentraOS

    In the MentraOS developer console, create an app. Set its Public URL to the HTTPS address that reaches your bridge on port 7010, for example a Tailscale Funnel or Cloudflare Tunnel hostname. Copy the package name and API key.

  2. Get a CI-Server memory key

    Companion Memory uses a memory-scoped CI-Server API key sent as x-api-key. It is not your Portal login. Issue one in CI-Server the same way you do for the Hermes and OpenClaw plugins.
