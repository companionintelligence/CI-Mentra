Companion Intelligence · Mentra Live

Your companion, in your glasses.

Companion for Mentra is a phone app for Mentra Live glasses. It connects to the glasses over Bluetooth with the Mentra Bluetooth SDK, the supported way for an app to talk to glasses directly. The iOS and Android apps are in development.

Developer preview

You can’t install Companion for Mentra yet. The iOS and Android apps are in development and have no store listing. The source is public on GitHub. To follow progress, join the Discord or read the Mentra Live docs.

The cloud app model this bridge used is retired. Mentra stopped running Cloud SDK apps with MentraOS 3.0 in August 2026. They ran only on Mentra’s separate MentraOS Legacy build, which Mentra said would end in October 2026. The legacy bridge setup below is kept for reference.

How it works

  1. Mentra Live glassesButtons and touchpad, microphone, camera and speaker. Models with a display, such as Even Realities G2, can show text
  2. BluetoothThe Mentra Bluetooth SDK connects the app on your phone directly to the glasses
  3. Companion appRuns on iPhone and Android. It scans for your glasses, shows their status and button or touch events, and sends text to glasses that have a display
  4. Companion HubPlanned: answers from your own Hub, Ollama or the hermes / openclaw agent
    Companion MemoryPlanned: recalls and saves your conversations in your own Companion Memory

Version 1 doesn’t upload audio, photos or video. Hub and Memory connections come in a later version, and the app’s privacy notice will say exactly what they send.

The web demo at /app/ shows what the companion UI looks like, with canned answers. The Bluetooth SDK doesn’t run in web browsers, so glasses connect through the phone apps.

Legacy bridge setup

Retired. This form builds the .env for the Cloud SDK bridge. That bridge can’t reach glasses under MentraOS 3.0, and new apps can’t be registered in the MentraOS console. It’s kept for reference. Nothing you type leaves this page. The file is built in your browser, then copied or downloaded.

  1. Register the app in MentraOS needs access

    In the MentraOS developer console, create an app. Set its Public URL to the HTTPS address that reaches your bridge on port 7010, for example a Tailscale Funnel or Cloudflare Tunnel hostname. Copy the package name and API key.

    A Cloud SDK app needs Mentra’s MentraOS Legacy build. As of 3 October 2026 the console shows only a “coming soon” page, so new apps can’t be registered there yet.

  2. Get a Companion Memory key

    Companion Memory uses a memory-scoped API key sent as x-api-key. It is not your Companion Intelligence sign-in. Issue one in Companion Memory the same way you do for the Hermes and OpenClaw plugins.
